## 1 Comprendre les principes de la programmation par aspect

### Exercice 1: Comprendre les termes de la programmation par aspect

1. **Aspect (aspect):** Entité logicielle qui capture une fonctionnalité transversale à une application.
2. **Point de jonction (join point):** Point dans le flot de contrôle d'un programme dans lequel un ou plusieurs aspects peuvent être appliqués.
3. **Point de coupe (pointcut):** Sélectionne un ensemble de points de jonction.
4. **Greffon (advice):** Bloc de code définissant le comportement d'un aspect.
5. **Mécanisme d'introduction:** Mécanisme d'extension permettant d'introduire de nouveaux éléments structuraux au code d'une application.
6. **Tissage (weaving):** Processus qui prend en entrée un ensemble d'aspects et une application de base et fournit en sortie une application dont le comportement et la structure sont étendus par les aspects.
