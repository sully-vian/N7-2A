# Cours d'OpenMP

Le Jupyter Notebook [`newcourse.ipynb`](newcourse.ipynb) et les fichiers [`aux.h`](aux.h) et [`aux.c`](aux.c) ont été générés à partir du fichier Org-mode [`newcourse.org`](newcourse.org) avec la commande

```sh
python3 ~/jupytorg/jupytorg src=newcourse.org dest=newcourse.ipynb
```

Cette commande fait utilisation de l'outil [Jupytorg](https://git.inpt.fr/net7/jupytorg) développé par [Net7](https://net7.dev/).
